SpendWise · editorial, second pass

Same world, properly built this time.

The palette and the serif stay. What changes is everything that made it read as generated: the stacked cards, the letter avatars, the pairs of equal buttons, and a Review screen that never showed you the message it was unsure about.

Review Was: two identical rounded cards, each with an Edit / Confirm pair, describing the problem in prose. A card nested inside a card. Now: the actual message text, with the words that caused the doubt marked. The decision is the two real answers, not a generic Edit.
Accounts Was: coloured letter avatars — and the colours were the category palette, used for something that isn't a category. Now: a typographic ledger. Section totals sit on the section headings, and the grand total is ruled off like a real statement.
Ledger Was: a 30px avatar on every row, so every row looked equally important. Now: category colour lives in a 2px gutter rule. Each day carries its own subtotal on the right.
Flow Was: a whole separate direction competing with this one. Now: a view inside Insights. The in/out spine you liked, over any period, with a running balance.

The flow view you liked now lives at Insights → Flow, with a period selector and a running balance, so it works over your whole history instead of only the last few days. It reads as an explorer you open, not a home screen you have to parse every time.

The rule I applied everywhere: colour encodes one thing only — category — and it lives in a 2px gutter, never in an avatar. Everything else is typography, hairlines, and a strict right-aligned numeric column. That is what separates a statement from a dashboard.
